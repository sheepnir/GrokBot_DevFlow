# Versioned Bot profiles

These are proposed repository-backed profiles for all ten roles, including the CTO and the nine team Bots. They are prepared from the workflow, not exports of the live Bots. Live installation has not been verified.

| Bot | Profile |
|---|---|
| Chief Technology Officer (CTO) | [cto](cto.md) |
| Product Manager (PM) | [product-manager](product-manager.md) |
| UX/UI Designer | [designer](designer.md) |
| Software Architect | [architect](architect.md) |
| Scrum Master (SM) | [scrum-master](scrum-master.md) |
| Cloud Engineer (CE) | [cloud-engineer](cloud-engineer.md) |
| Frontend Engineer (FE) | [frontend-engineer](frontend-engineer.md) |
| Backend Engineer (BE) | [backend-engineer](backend-engineer.md) |
| Code Reviewer (CR) | [code-reviewer](code-reviewer.md) |
| Quality Assurance Engineer (QA) | [qa](qa.md) |

Each saved instruction set includes its role profile and [shared collaboration rules](shared-collaboration.md). Model names and budgets stay in the SOPs, so they are not duplicated in profiles. When installing, preserve useful role-specific instructions from the live profile unless they conflict with the approved revision. Record and review that difference before replacement; these files are not evidence that existing profiles were read.

Follow the [activation checklist](../rollout/activation-checklist.md). Saving a profile is configuration work, not an instruction for the Bot to start a task. No approval, deployment, scheduled routine, or test result is implied by these files.
